AI Agent for Crypto Wallet Permissions

Python · FastAPI · NVIDIA NOOA · OpenRouter · PostgreSQL · React · Docker · GitHub Actions · Cloudflare

  • Built and launched a web app that lists every token permission an Ethereum or Monad transaction granted, and flags which ones are still active and risky today.
  • Added an AI agent that investigates each spending contract using 3 read-only tools within a fixed call limit; it can cite only facts the code has verified, and the app falls back to rule-based results if the AI gets it wrong.

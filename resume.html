TraceIntel

Evidence-Grounded Security Agent

Python · FastAPI · NVIDIA NOOA · OpenRouter · PostgreSQL · React · Docker · GitHub Actions

  • Built a planner–reporter LLM agent that checks which token permissions a crypto transaction left open and advises revoke, verify or review; it uses 3 typed read-only tools, capped at 8 calls over 2 rounds.
  • Grounded every claim: a validator rejects any sentence not backed by code-computed evidence, invalid output gets one repair attempt, and a rule-based baseline answers when the model fails.
  • Wrote 24 offline evals that run in CI: 8 labelled agent scenarios and 5 adversarial cases (prompt injection, out-of-scope tool calls, fabricated claims), alongside 95 automated tests.
  • Shipped it behind a FastAPI + PostgreSQL API with per-client hourly rate limits, daily caps of 100 analyses and 20 LLM runs, and stored traces of every model call and its latency.

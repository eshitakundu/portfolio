What it does

Paste an old transaction and see which token permissions it left behind are still live, explained by an agent that may only cite verified evidence.

How it's built

A NOOA planner calls 3 typed, read-only tools under a budget enforced in code. The reporter can only cite claims the tools verified, and falls back to a deterministic report.

What it does

Name a package and point ARIS at your repo. Seven parallel branches gather evidence from 8 sources, and you get an emailed brief with an adopt, trial, hold or avoid verdict.

How it's built

Runs on my self-hosted fork of Heym. I proposed its Python exec node upstream, and the maintainers of the 1.7K-star project shipped it as a native feature.

  • 104 node DAG with 7 evidence branches running in parallel ↗
  • 18 Python nodes compute every score; LLMs only extract and narrate ↗

ProblemThe real opinions about a dev tool are buried in long Hacker News threads, and AI summaries of those threads can make up quotes.

Try it live ↗Code ↗
How it works +
What it does

Ask what developers think of a tool and get pros and cons where every point quotes a real Hacker News comment and links to it.

How it's built

The model only proposes. A validator keeps a point only if its quote appears word for word in the comment it cites, with one repair round and a rule-based fallback.

  • 149 verbatim-cited points in a live run over 20 tools ↗
  • 18/19 model reports passed the quote validator ↗
  • 0.27 s cached response, down from 17.8 s, with Cloudflare D1 ↗
